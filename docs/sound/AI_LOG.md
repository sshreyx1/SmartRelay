|---|---|---|---|
| 2026-11 (before plan) | Species ID on the backend: BirdNET run on an audio clip sent from the node. | Moves the main analytics off the Pico, against the brief, and costs airtime and RAM on the node. | Rejected. Species ID was redesigned to run on-device. |
| 2026-11-02 | Plan step A0: start sound work on a fresh `feature/sound-classifier` branch cut from `main`. | `git log main..sound` showed `sound` is identical to `origin/curveball` (12 commits ahead of `main`) and holds `firmware_smp/`, which T3's µT-Kernel half needs; a branch off `main` would drop it. | Stay on `sound`. |
| 2026-11-02 | Plan step A0: macOS setup `python3 -m venv .venv`. | On R's Mac `python3` is 3.14; a pip dry-run resolve showed the pinned numpy/scipy have wheels for 3.11/3.12 only, so the install would try to compile and fail. | `ml/README.md` names `python3.11`/`python3.12` explicitly (pending R's review). |
| 2026-11-02 | Plan rule 12: `.gitattributes` line `*.uf2 *.npy *.scl *.jpg *.png *.wav binary`. | `git check-attr` printed `*.npy is not a valid attribute name`: gitattributes takes one pattern per line, so the extra patterns were read as attributes and only `*.uf2` would match. | One `<pattern> binary` line per extension (pending R's review). |
| 2026-11-03 | Plan A3: int16 Q15 FFT with a fixed >>1 per stage (1/256 overall). | A quiet frame (a few ADC counts, i.e. ambient) comes out of a fixed-scale 8-stage integer FFT as mostly rounding noise. | 2026-11-03 | Plan A5: reject the stage-2 label on stage-2 confidence alone, so that ≤ 15% of the emitted labels are wrong. | On the backup data the rule picked threshold 101 (never emit an animal label): captures stage 1 put in the wrong group still get some animal label, and no stage-2 threshold can remove those. Verified by running `train.py` with that rule: threshold 101, coverage 0%. | Switched to combined confidence c1·c2/100 (DECISIONS D5); **accepted by R**. |
| 2026-11-03 | R asked for a fast grid (DT 6/8, RF n=10 d=8) for the backup model. | The fast grid's test group macro-F1 was 0.591, below the plan's own 0.6 stop rule; the full grid took only 3 s and gave 0.613 within the flash budget. | Claude exported the full grid (DECISIONS D4); **accepted by R**. |
| 2026-11-03 | Wikimedia Commons search results used directly as label images. | A contact sheet showed off-topic hits (a pig skull, a sheep skeleton, an empty field for "cow", roots for "human") and identifiable people, including a child. | Hand-picked replacements, identifiable people dropped, credits regenerated (35 images). |
